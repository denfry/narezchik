02

Конвейер одного Shorts

Команда /shorts input/podcast.mp4 5 прогоняет видео через роли по очереди. Состояние хранится в файле плана, поэтому работу можно прервать в любой момент и продолжить потом.

  1. ТехникПринимает файл, проверяет параметры, делает транскрипт.код
  2. СкаутЧитает транскрипт целиком, предлагает таблицу моментов. Вы выбираете, какие брать.модель
  3. СценаристЧерновик нарезки по паузам делает скрипт, модель ставит хук, режет воду и повторы.модель
  4. МонтажёрКроп на говорящего (скрипт), наезды, акценты в субтитрах, подложка, мост в лонг.модель
  5. ТехникВалидация плана, рендер строго по одному, технический контроль файла.код
  6. КритикНезависимо оценивает ролик по 8 параметрам, возвращает правку конкретной роли.модель
  7. УпаковщикЗаголовки, описание, теги, закреп, промпт обложки, расписание публикаций.модель

Лонг идёт тем же путём, но скаут предлагает структуру с главами, а монтирует отдельная роль: карточки глав, фразовые субтитры, музыка только на стыках.

03

Как запустить

Что нужно

СистемаWindows, macOS или Linux
Python3.10–3.12 (на 3.13 может не встать mediapipe)
Память4K-рендер лонга держит 6–9 ГБ RAM — комфортно от 16 ГБ
Видеокартане обязательна; NVIDIA ускоряет транскрипцию примерно в 10 раз
Дискисходник подкаста в 4K — 10–40 ГБ
АккаунтыClaude (Pro или выше), Google Cloud для YouTube API-ключа

Шаги

  1. Поставить Claude Code — установщик на claude.com/claude-code, вход через подписку.
  2. Скачать проект и запустить установщик. Он сам поставит ffmpeg, whisper, mediapipe и покажет, чего не хватает. 
    install.cmd --auto      # Windows
./install.sh --auto     # macOS / Linux
  3. Открыть папку в Claude Code (claude) и один раз принять доверие папке.
  4. Подключить канал: /setup-channel @канал. Ключ YouTube API — бесплатно, 3–5 минут.
  5. Положить видео в input/ и дать команду: 
    /shorts input/podcast.mp4 5

Готовые ролики появляются в output/. /fix <ролик> <что не так> — точечная правка, /pack — упаковка и лист публикации. Проверить установку: python install.py --check.

Из чего складывается

Часть расходов не зависит от числа роликов: приём видео и скаут платятся один раз на исходник. Остальное — на каждый ролик.

$0,07 + $0,39 × часы + $2,37 × N N — сколько Shorts берёте из одного исходника.
Круг правок после критика — ещё примерно +$0,8 на ролик.

05

Потянет ли массовый нарезчик

Всё, кроме Claude, бесплатно, поэтому вся экономика сводится к одной цене — стоимости ролика в токенах и вашему времени на проверку.

Объём в месяцAPI, без правокAPI, круг правок на каждомЧто подойдёт
30 Shorts (1 в день)≈ $75≈ $100Pro, если уложитесь в лимит; иначе Max 5x
100 Shorts≈ $250≈ $335Max 20x или API
300 Shorts (10 в день)≈ $750≈ $1 000API; Max 20x + его кредиты как часть объёма

Как прикинуть выгоду

прибыль с ролика = ваша ставка − $2,5…3,4 − ваше время × цена часа Ваше время — это выбор моментов из таблицы скаута, просмотр готового ролика и правки словами.
Сам монтаж, субтитры и рендер — без вас.

Где упрётесь при потоке

  • Рендер — по одному. Параллельно ролики на одной машине не рендерятся, иначе не хватит памяти. Для потока — второй ПК или VPS.
  • Квота YouTube API — около 6 загрузок в день на проект. Больше — через Studio вручную или несколько проектов.
  • Непроверенный API-проект грузит ролики только приватными. До аудита YouTube открывайте их вручную.
  • Окна лимита подписки. Упёрлись посреди пачки — ничего не теряется, продолжаете после сброса с того же шага.

Как держать цену ниже

  • Брать 5–10 роликов с одного исходника: скаут платится один раз.
  • Отсеивать слабые моменты до монтажа, а не после.
  • Править конкретно: «хук длинный, начни с „Никогда“», а не «переделай».
  • /clear между пачками: старый контекст оплачивается в каждом сообщении.
  • Отключить лишние MCP-серверы в Claude Code.

Оплата из России. Россия не входит в список стран, где Anthropic официально предоставляет сервис, поэтому подписка и API оплачиваются зарубежной картой. Заложите это в расчёт: комиссии посредников могут добавить к цене заметный процент.
