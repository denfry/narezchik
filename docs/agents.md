# Команда агентов и команды

Нарезчик — это не один большой промпт, а редакция из девяти ролей. У каждой свой узкий
набор инструкций (skills), своя модель и свой участок работы. Общаются они не друг с
другом, а через файл плана `edit-plans/<clip_id>.json`: каждый читает, что сделали до
него, пишет свою секцию и двигает `project.stage`.

## Роли

| Агент | Модель | Что делает | Skills |
|---|---|---|---|
| `channel-analyst` | Sonnet | разбирает канал, пишет профиль, бренд, правила | — |
| `idea-scout` | Sonnet | ищет моменты для Shorts, темы лонгов, контент-план | viral-moment-finder, long-form-structure |
| `scriptwriter` | Sonnet | собирает речь: хук, вырезка воды, порядок, удержание | shorts-script-editor, long-form-structure, retention-editor |
| `shorts-editor` | Sonnet | монтаж вертикали: кроп на говорящего, акценты, пословные субтитры, подложка, байт-мост в лонг | visual-director, cta-director, subtitle-director, sound-designer |
| `long-editor` | Sonnet | монтаж лонга: главы и карточки, наезды, врезки, байт в середине, фразовые субтитры, музыка на швах | те же + broll-researcher |
| `render-engineer` | Haiku | приём видео, транскрипция, рендер, техконтроль | video-ingest, transcription, ffmpeg-editor |
| `qc-critic` | Sonnet | независимо оценивает ролик, возвращает правки адресно | shorts-qc |
| `packager` | Sonnet | заголовки, описания, закрепы, обложки, расписание | packaging |
| `community-manager` | Sonnet | черновики ответов на комментарии, правила модерации | — |

Техник на Haiku, потому что его работа — запустить скрипт и прочитать результат, а
Haiku расходует лимит подписки заметно медленнее. Модель можно поменять в поле `model:`
файла агента (`.claude/agents/<имя>.md`): `sonnet`, `opus`, `haiku` или `inherit`
(как в основной сессии).

Главная сессия Claude Code — **продюсер**: команды ниже говорят ей, кого и в каком
порядке звать. Сама она не монтирует.

## Команды

| Команда | Что делает |
|---|---|
| `/setup-channel [@канал]` | подключить канал, собрать профиль (docs/setup-channel.md) |
| `/ideas [источник]` | идеи по видео или контент-план по всем транскриптам |
| `/shorts <видео> [N]` | N готовых Shorts из длинного видео |
| `/long <видео \| сценарий>` | один лонг 5–15 минут |
| `/fix <clip_id> <что не так>` | точечная правка готового ролика |
| `/pack <clip_id \| префикс> [дата]` | упаковка и расписание, по желанию загрузка на YouTube |
| `/comments [reply \| moderate]` | ответы на комментарии и автомодерация (docs/comments.md) |

Команды можно не набирать: «сделай 5 шортсов из input/podcast.mp4» сработает так же.

## Конвейер Shorts

```
input/видео.mp4
  │ render-engineer ── probe → edit-plans/<id>.json, транскрипт transcripts/<id>.json/.txt
  ▼
  │ idea-scout ─────── кандидаты → вы подтверждаете → edit-plans/<id>_shortNN.json   [moment_selected]
  ▼
  │ scriptwriter ───── auto_cut.py + хук + retention (все планы за один запуск)       [retention_passed]
  ▼
  │ shorts-editor ──── autoframe.py, визуал, CTA, build_subtitles.py + акценты, звук  [audio_planned]
  ▼
  │ render-engineer ── validate → render_short.py (по одному) → qc_video, лист кадров  [rendered]
  ▼
  │ qc-critic ──────── оценки 0–10 → pass / needs_fix «кому и что»                    [final]
  ▼                     └─ needs_fix → откат stage → нужный агент → перерендер (лимит кругов)
  │ packager ───────── заголовки, описания, закрепы, лист публикации
  ▼
output/<id>_shortNN.mp4
```

Лонг — тот же конвейер, но `idea-scout` предлагает структуру (хук с обещанием, главы),
сценарист собирает 5–15 минут, а монтирует `long-editor`: у него другие правила —
главы и карточки, фразовые субтитры, музыка только на швах, байт на оффер в середине.
У `shorts-editor` — кроп на говорящего, пословные субтитры и байт-мост в лонг.

## Почему так, а не «один умный агент»

- **Узкий контекст.** Монтажёру не нужен весь двухчасовой транскрипт, сценаристу — правила
  цветокора. Каждый получает только своё — меньше путаницы и меньше расход лимита.
- **Независимый критик.** Агент, который монтировал, свой ролик хвалит. Критик видит его
  впервые и возвращает правку конкретному исполнителю.
- **Прерываемость.** Всё состояние — в файле плана. Можно закрыть Claude Code посреди
  монтажа и продолжить завтра: `stage` покажет, с какого шага.
- **Скрипты делают арифметику.** Нарезка по паузам (`auto_cut.py`), субтитры
  (`build_subtitles.py`), кроп по лицу (`autoframe.py`), рендер — детерминированный код.
  Модель принимает только редакторские решения.

## Запуск без диалога (скрипты, cron)

Команды рассчитаны на интерактивный Claude Code: продюсер запускает агента в фоне и
продолжает, когда тот закончил. В режиме `claude -p` сессия завершается, не дождавшись
фонового агента, поэтому для автоматизации запускайте стадии по одной:

```bash
claude -p "Найди моменты для Shorts в podcast12 и создай планы на 3 лучших" --agent idea-scout
claude -p "Собери речь для планов edit-plans/podcast12_short0*.json" --agent scriptwriter
claude -p "Смонтируй планы edit-plans/podcast12_short0*.json" --agent shorts-editor
claude -p "Отрендери планы podcast12_short0* и проведи техконтроль" --agent render-engineer
```

Папку нужно один раз открыть в Claude Code интерактивно и принять диалог доверия — иначе
разрешения из `.claude/settings.json` не применяются.

## Как добавить свою роль

Файл `.claude/agents/<имя>.md` с frontmatter `name`, `description` (когда звать),
`tools`, `model`, `skills` и инструкцией. Если роль участвует в конвейере — добавьте её
в нужную команду (`.claude/skills/shorts/SKILL.md` и т.д.).
