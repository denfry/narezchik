# Учебник монтажа нарезок: Shorts и длинные ролики из разговорного видео

Общие правила монтажа и упаковки нарезок из подкастов, интервью, дебатов и монологов: драматургия, визуал, субтитры, звук, упаковка, метрики, чек-лист.
Профиль конкретного канала лежит в `channel/profile.md` (стиль спикера, палитра, CTA, запреты) и **имеет приоритет** над общими правилами этого файла.

---

## 0. Как читать этот файл

Метки доказательности (стоят у правил, где это важно):

- **[офиц.]** — справка или официальный блог YouTube.
- **[YouTube]** — сотрудник YouTube в официальном видео или интервью.
- **[практика]** — консенсус нескольких независимых практиков с замерами или данные реальных каналов.
- **[эксперт]** — один авторитетный практик.
- **[гипотеза]** — правдоподобно, данных нет, проверять экспериментом.
- **[ориентир]** — рабочее число из практики, не догма. Сдвигайте под свои данные.

Базовый принцип: каждая монтажная операция отрабатывает функцию — удержание, ясность, любопытство, эмоция, сокращение паузы, подготовка payoff. Эффект «для красоты» — лишний. Монтаж делает спикера убедительнее, а не превращает его в мем.

**Формат решает больше, чем монтаж** [практика]. Один и тот же пайплайн на диалоге/споре с собеседником и на соло-монологе даёт кратную разницу в удержании. Соло-монолог без оппонента, особенно «мотивационный», — стабильно самый слабый кластер. При выборе материала это первый фильтр, а не последний.

Ничего из этого не гарантирует вирусность. Это система, которая убирает известные причины свайпа и повторяет то, что статистически работает.

## 1. Драматургия

### 1.1 Общая схема: HOOK → CURIOSITY → VALUE/TENSION → PAYOFF

- **HOOK** — зацепить: вопрос, цифра, клеймо, конфликт. Без приветствия.
- **CURIOSITY (foreshadowing)** — сразу после хука дать понять, что будет и в чём конфликт [эксперт]. Без этого сильный хук «сгорает» за 5–9 секунд.
- **VALUE / TENSION** — эскалация: реплика → возражение → аргумент → цифра, каждая ступень сильнее.
- **PAYOFF** — ответ, который дословно закрывает обещание хука и заголовка. Никогда в первой трети.

Расширенная цепочка упаковки: **PROMISE** (заголовок + обложка / первый кадр) → **FIRST FRAME** (визуально повторяет обещание) → **HOOK** (произносит обещание вслух и добавляет ставку) → **PROOF** (первый факт, что обещание выполнимо) → **ESCALATION** → **PAYOFF**. Первая минута должна доказать, что обложка не врёт [эксперт].

Проверка обещания: выписать обещание из заголовка и найти таймкод, где оно закрыто. Нет таймкода — менять заголовок или монтаж. Незакрытое обещание бьёт по каналу сильнее, чем слабый хук: YouTube учитывает опросы удовлетворённости, и «досмотрел, а развязки нет» — минус [YouTube].

### 1.2 Связность: «но / поэтому», а не «и ещё»

- Каждая следующая мысль связана с предыдущей через «но» или «поэтому» [эксперт].
- Тест: если между двумя кусками можно вставить «и ещё» — второй кусок кандидат на вырезание.
- Перечисление без роста ставок дольше ~8 с — точка отвала. Либо сжать в плашку-список, либо вырезать.
- Сегмент не начинается с середины мысли («…и поэтому», «вот, и соответственно»).

### 1.3 Механики удержания и где они фальшивят

| Механика | Работает | Фальшь |
|---|---|---|
| Information gap | плашка с числом без ответа | плашка, не совпадающая с речью |
| Open loop | «три причины, третья неочевидная» | обещание, которое ролик не закрывает |
| Escalation | реплика → возражение → жёсткий ответ → панчлайн | перечисление без роста ставок |
| Pattern interrupt | смена формата или ракурса ровно на смысловом переходе | зум/whoosh по таймеру |
| Re-hook | новая цифра/вопрос каждые 60–90 с лонга; вторая реплика собеседника на 15–20 с шортса | смена главы без новой мысли |
| Setup → payoff | payoff в последних 8–10 с шортса, обрыв без прощания | payoff на 16-й секунде, до него вода |
| Conflict | собеседник в кадре спорит или растерянно молчит | монолог без оппонента |
| Stakes | конкретная цифра, потерянные годы, последствия | абстрактная «мотивация» |
| Visual novelty | реакция слушающего 1–1,5 с без слов | b-roll «для заполнения» |
| Audio novelty | тишина → включение музыки на смене формата | SFX на каждый стык |
| Compression | вырезать мычание, повтор мысли тремя формулировками | резать паузу перед панчлайном — это инструмент |

### 1.4 Хук Shorts (0–3 с)

- Первая секунда — сразу речь. Лицо с эмоцией + триггер-слово + плашка ≤5 слов, **дословно совпадающая** с тем, что звучит в 0–2,5 с.
- Первый кадр + первое слово = обложка: в ленте свайпов заголовок и обложка не видны [офиц.].
- Первый кадр держат почти все ролики; теряют на **5–9 секунде** — там, где зритель понял тему и увидел, что конфликта нет [практика]. Поэтому 3–7 с — foreshadowing, а не вводная.
- Самая сильная реплика куска часто лежит на 10–20-й секунде исходника. Переносите её в 0:00, контекст — после или в плашку.

### 1.5 Хук лонга (0–30 с)

- **0–5 с** — сцена узнавания, шок-факт или реплика оппонента. Крупный план лица, без приветствия.
- **5–15 с** — развитие факта, первая эмоция.
- **15–30 с** — обещание структуры («разберу три причины, третья — неочевидная») + первая плашка-тезис. Без обещания зритель уходит на второй минуте, даже если первая была сильной.
- **30–60 с** — первая ценность. Бэкстори и «кто я» — не раньше 2-й минуты, как доверие, одной фразой.
- «Intro» = доля оставшихся через 30 с — единственный официальный порог удержания [офиц.]. «Первый акт — награда, а не введение; slow burn не работает» [YouTube].
- **Кадр 0 — крупное лицо говорящего**, не рука, не стол, не общий план. Главная автопроигрывает начало без звука — первые секунды работают как превью [практика].
- **Сильнейшая реплика — до 0:30, без разгона.** Проверка перед рендером: что услышит зритель, который уйдёт на 0:30? Если не лучший момент ролика — перестроить хук.
- Самопрезентация перед первой ценностью («у меня большой блог…») даёт один из худших результатов удержания [практика].

Типы хука лонга: cold open (сцена узнавания) — основной; шок-цитата/статистика; реплика оппонента; результат сначала (для историй); вопрос-дилемма; провокационный тезис (только если закрыт в payoff). Не использовать: тизер-нарезку будущих моментов (у говорящей головы выглядит как реклама), самопрезентацию, приветствие.

## 2. Shorts

### 2.1 Длительность

- Shorts — до 3 минут [офиц.]. Идеальной длины нет; исследования противоречат друг другу. **Процент просмотра важнее длины** [практика].
- Ролики разной длины сравниваются раздельно — удержание оценивать относительно роликов своей длины [YouTube].
- Рабочие ориентиры [ориентир]: диалог/спор 35–70 с, монолог 30–45 с. Дольше 60 с — только если внутри есть эскалация (две реплики собеседника и панчлайн).
- Short длиннее 1 минуты с любым copyright-claim блокируется глобально [офиц.] — музыка только своя или из библиотеки.

### 2.2 Таймлайн

| Отрезок | Зритель должен | Монтаж |
|---|---|---|
| 0,0–1,0 с | увидеть лицо с эмоцией, услышать триггер, прочитать плашку ≤5 слов | речь с кадра 0; без обложки и логотипа |
| 1–3 с | понять конфликт: кто против кого, какая цифра | кроп на того, кто говорит |
| 3–7 с | захотеть ответа | foreshadowing; первая смена плана по реплике |
| 7–15 с | получить первый аргумент/ставку | средняя плотность; реакция слушающего ~1 с |
| 15–30 с | эскалация: возражение → ответ, цифра | высокая плотность на обмене репликами; punch-in на цифре |
| 30–50 с | развитие до пика | реакция собеседника; смена формата, если есть |
| последние 8–10 с | payoff/панчлайн | punch-in, music-stop, обрыв сразу после слова |
| хвост ≤1,5 с | CTA «подпишись» | не перекрывает последнее слово |

Payoff — на 55–80 % хронометража, никогда рано [эксперт].

### 2.3 Формулы и типы первого кадра

Хуки по убыванию надёжности для разговорного материала:

1. **Вопрос или претензия собеседника** — «А почему ты…?», «С таким я бы никогда…». Лучший тип для диалогов [практика].
2. **Вопрос ведущего гостю** — «Как думаешь, что самое ценное в …?».
3. **Цифра-шок** — «один на сто тысяч», «в 4 раза чаще».
4. **Клеймо / сильное утверждение** — «Это манипуляция».
5. **Список с пропуском** — «7 пунктов, важные 4-й и 7-й» [эксперт].
6. **Личное признание / результат сначала** — «Я несколько лет не делаю X».
7. **Неожиданный ответ сразу** — короткая реплика, ломающая ожидание.
8. **Табу-слово с бипом** — только если оно реально есть в речи [эксперт].
9. **Redacted pull-forward** — финальная фраза ролика в начале, ключевое слово заглушено [эксперт].
10. **Диалог пинг-понг** — «— X. — Что? — X.» за первые 2 с.
11. **Скриншот/комментарий**, с которого начинается разбор.
12. **Жест-пауза** — 0,4 с тишины, потом удар первым словом ([гипотеза], только для острых тем).

Не первый кадр: логотип, обложка-картинка, приветствие, «в этом видео», тема-название («сегодня про…»), спикер в паузе без слова, общий тезис без конфликта.

### 2.4 Заголовок

- **2–5 слов ударом** или вопрос с провокацией работают лучше длинного описательного вопроса [практика].
- Реплика собеседника или панчлайн как заголовок — сильный вариант для диалогов [практика].
- Без @-упоминаний внутри заголовка; хэштеги (3–7 тематических) — в хвост или в описание. `#shorts` не обязателен.
- Заголовок в ленте свайпов не виден — он нужен для страницы канала, поиска и ленты подписок.

### 2.5 Re-hook внутри шортса

- Вторая реплика собеседника на 15–20 с — естественный re-hook в диалоге.
- В монологе — цифра или поворот («но») в середине, с punch-in.
- Последние 8–10 с — ускорение плотности до высокой, даже если ролик был спокойным.

### 2.6 Финал и петля

- Обрыв **на панчлайне** — приём. Обрыв **на полуслове** — брак.
- После панчлайна допустимо 0,3 с тишины (пересмотр), затем конец.
- Loop — только если последняя фраза естественно возвращает к первой. Искусственно не строить: петли не увеличивают engaged views [офиц.].
- CTA «подпишись» ≤1,5 с: длинный байт срезает последние проценты кривой [практика].
- Длинный CTA-баннер с мелким текстом на 2 с не читается и рвёт кривую. Если нужен бренд — 2–3 коротких касания-плашки по 2–3 с в паузах между тезисами, не поверх лица ([ориентир], детали — в профиле канала).

### 2.7 Из длинного исходника в шортс (порядок работы)

1. Транскрипт с пословными таймкодами + вычитка до рендера.
2. Найти момент: самостоятельный фрагмент с конфликтом, цифрой, клеймом или историей, понятный без контекста.
3. Перестроить начало: первым кадром — самая сильная реплика.
4. Убрать контекст «до»: либо в плашку ≤5 слов, либо вырезать.
5. Переставить реплики — только если это не меняет смысл.
6. Добавить плашку-хук дословно по первой фразе + foreshadowing.
7. Эскалация; вырезать повторы и мычание; паузы перед ударом оставить.
8. Визуал: кроп по репликам, реакции, 1–2 punch-in.
9. Payoff в последних 8–10 с, обрыв на слове.
10. Субтитры из вычитанного транскрипта.
11. Звук, QC, упаковка.

Из часа подкаста обычно получается 15–25 кандидатов, в работу стоит брать 12–15, выкидывая куски с паузами и неясным контекстом ([гипотеза], русскоязычные практики). Монологов в этом наборе — меньшинство.

## 3. Длинные ролики (5–15 мин)

### 3.1 Структура

- **HOOK → PROMISE → 3–6 глав с функцией → PAYOFF → CTA.**
- Функции глав: диагноз, механика, история, практика, возражение, вывод. Глава без функции — кандидат на удаление.
- Каждая глава добавляет новый факт, пример, механизм, возражение или вывод. Повтор одного тезиса в разных словах сжимается до самой чёткой версии.
- Главы по 60–120 с [ориентир]; блоки по 3–5 минут с явным титром главы [практика].
- Границы глав = таймкоды в описании. Это и структура монтажа, и навигация.

### 3.2 Таймлайн

| Отрезок | Что происходит | Монтаж |
|---|---|---|
| 0:00–0:05 | шок-факт/сцена узнавания, первое слово с кадра 0 | крупный план, плашка ≤5 слов дословно |
| 0:05–0:15 | развитие, первая эмоция | punch-in на цифре |
| 0:15–0:30 | обещание структуры | плашка «3 ПРИЧИНЫ», вход музыки (если есть) |
| 0:30–1:00 | первая ценность | плашка «1. …» |
| 1:00+ | главы, каждая с новым поводом остаться | re-hook каждые 60–90 с; ≤45 с без визуального изменения |
| первая треть / шов | мягкий CTA ≤15 с | в смысловом шве между главами |
| после 2:00 | личная история как доверие | низкая плотность, музыка тихо |
| последняя глава | практика/что делать | плашки «ШАГ 1/2/3» |
| финал | payoff, закрывающий обещание | punch-in, music-stop |
| конец | полный CTA ≤30 с + конечная заставка 5–20 с | заставка на следующий ролик/серию |

### 3.3 Re-hook и провалы удержания

- **Каждые 60–90 с — новый повод остаться**: изменённый вопрос, цифра, пример, поворот аргумента, визуальный акцент. Смена главы сама по себе re-hook'ом не является.
- Первые 30 с — смена картинки каждые 10–15 с; дальше — не реже раза в 60–90 с [практика].
- **Нет отрезка >45 с без визуального изменения**, если содержание даёт смысловую точку для смены [ориентир]. Более 75 с без визуального события — жёсткий флаг.
- Типичные причины провалов (dips) [практика]: длинный монолог собеседника без перебивок; повтор мысли 2–4 формулировками; пик спора на общем плане; рекламный блок посреди аргумента; самопрезентация в начале.
- «Опасные зоны» — переходы, концы сюжетных линий, тяжёлый контекст — сокращать до минимума [эксперт].
- Ориентир по формату [практика]: голая говорящая голова 8–15 мин держит заметно хуже, чем структурный формат с главами и графикой.

### 3.4 CTA-врезки

- **Мягкий CTA — в первой трети или около середины, до 15 секунд, в смысловом шве между главами**, после первой отданной ценности. Не рвать аргумент.
- **Полный CTA — в конце, до 30 секунд.**
- **Никогда** не вставлять 60–110-секундный рекламный блок посреди аргумента — это главный retention-killer лонга [практика].
- Врезка со своим звуком, записанная на другом уровне громкости, выравнивается отдельно до общей нормализации (общий loudnorm провал в 10+ LU не вытягивает).
- Смена одежды/локации внутри ролика без монтажной мотивации (врезка из другой съёмки) воспринимается как шов — давать её с плашкой или сменой музыки.

### 3.5 Концовка и конечная заставка

- Финал — payoff, затем CTA. Обрыв на полуслове недопустим: fade out и заставка.
- Конечная заставка: видео ≥25 с, последние 5–20 с, до 4 элементов [офиц.]. **Проверить, что она реально настроена в Studio** — без неё досмотревшие до конца уходят в никуда.
- На ТВ и в длинном просмотре работают серии: зритель выбирает серию и не решает заново [YouTube]. Заставка и плейлист ведут на следующий ролик серии.

### 3.6 Мост Shorts → лонг

- Ярлыка «шортс-канала» не существует; оценивается каждое видео, а не канал [YouTube].
- Рекомендации учитывают лонги каналов, которые зритель смотрит в Shorts [YouTube]. Мост работает при совпадении темы и аудитории в одно время.
- Горизонтальный клип 1–3 мин из того же момента — для YouTube это лонг; такие клипы дают кратно больше подписчиков на просмотр, чем Shorts [эксперт].
- Связка «тема недели»: Shorts → горизонтальный клип → лонг, со ссылками в закрепе и заставке.
- Два канала — только если аудитории разные [YouTube].

## 4. Визуал

### 4.1 Кроп и «камера следует за голосом»

- В кадре — тот, кто говорит. Переключение на собеседника — по началу его реплики, не позже ~0,3 с [ориентир].
- Реплика собеседника за кадром дольше ~2 с при камере на слушающем — брак. Мультикам в исходнике часто отстаёт от говорящего — сверять по транскрипту, кто говорит, и по детекту лиц, кто в кадре.
- **Реакция слушающего 1–1,5 с без слов** после сильного заявления — лучший «спецэффект» диалога [практика].
- Если реакция группы слышна («Что?!»), она должна быть и видна — врезка общего плана.
- База вертикали: средний план, лицо ~40 % высоты кадра, глаза на 35–40 % от верха [ориентир].
- Технически: окно 9:16 из кадра 1920×1080 имеет ширину ~608 px, а не 1080. Центр окна — на лице говорящего; на общем плане с двумя лицами — на говорящем, не на слушающем. После рендера — лист кадров по сегментам до публикации.
- В горизонтали кропать нечего: координаты вертикального кропа прижимать к границам кадра.

### 4.2 Punch-in и линия глаз

- Punch-in 110–118 %, не 130 % [ориентир]. Один-два на 60 с. Только на цифре, клейме, панчлайне.
- Плавный наезд (ease/smoothstep), без рывков по таймеру.
- **Линия глаз постоянна при смене крупности**: при зуме глаза остаются на той же высоте кадра (~38–42 % для вертикали). Тогда смена крупности читается как вторая камера, а не как скачок. Зум от центра кадра уводит глаза вверх тем сильнее, чем крупнее наезд [практика].
- Без выравнивания по глазам — держать наезд в пределах 8–12 %.
- Лонг: punch-in до ~115 %, на цифрах и границах глав.

### 4.3 Микро-зум статики

- Любой статичный кусок длиннее ~8 с получает еле заметный наезд («на миллиметр») [практика]. Цель — кадр не мёртвый.
- На длинных монологах лонга — медленные наезды/дрейфы 4–6 % [практика].
- Микро-зум — не замена смене плана по смыслу, а страховка для статики.

### 4.4 Плотность визуальных изменений

«Склейка каждые 2 секунды» не подтверждена ни одним источником [практика]. Замеры топ-клип-каналов: визуальное изменение каждые 3–8 с (жёсткие склейки 4–6 с), ускорение до 2,5–3 с перед payoff, одна смена ракурса ровно на смысловом переходе. Для взрослой аудитории (35+) зум + whoosh на каждой фразе **снижает** удержание [практика].

| Плотность | Интервал | Где | Инструменты |
|---|---|---|---|
| Низкая | 8–15 с | личная история, эмоция, плотная аргументация лонга | один план, медленный наезд ≤108 %, паузы сохранены |
| Средняя | 4–8 с | объяснение механики, данные, главы лонга | punch-in на цифрах, плашки-тезисы, реакции |
| Высокая | 2,5–4 с | спор, обмен репликами, перечисление ставок, последние 10 с перед payoff | смена говорящего по репликам, реакции, смена формата, music-stop |

Правила:
1. Плотность задаётся содержанием, не таймером. Смена плана — на границе реплики, тезиса, примера.
2. Ускорение к payoff: последние 8–10 с шортса — высокая плотность.
3. Для взрослой аудитории на монологах — не выше средней.
4. «Сырой» монтаж работает у уже больших авторов; для новых каналов быстрые цепкие клипы по-прежнему строят аудиторию [практика].

### 4.5 B-roll

- При сомнении, нужен ли b-roll, — не нужен. Хороший кроп говорящей головы лучше нерелевантной иллюстрации.
- **Не больше ~4 вставок на минуту речи, по 2–3 с** [ориентир], и только там, где слово можно показать буквально.
- У топ-клип-каналов b-roll занимает единицы процентов хронометража [эксперт].
- Свой уникальный материал (съёмки спикера, закулисье) — в приоритете над стоком.
- Стоковый b-roll «для заполнения» и b-roll, закрывающий лицо на сильной фразе, — ошибки.

### 4.6 Текст на экране

- **Плашка-хук**: 1–2 строки, ≤5 слов, 0–2,5 с, дословно совпадает с первой фразой. Если без звука первые секунды важны — держать дольше (до ~6 с).
- **Плашки-тезисы**: белый жирный гротеск на контрастной подложке, по центру, 1,5–3 с. В лонге не чаще одной на 60–90 с, на границах глав; в шортсе — хук + максимум одна на панчлайн.
- Плашки **анонсируют** («3 правила», «смотри ошибку»), а не повторяют сказанное [практика].
- Цифра крупно в момент, когда её произносят, — сильный приём для rewatch.
- Длинный текст (описание, список мелким шрифтом) поверх кадра не читается и перекрывает субтитры.
- Визуальная иерархия: лицо (эмоция) → субтитр → плашка → бренд. Никогда четыре элемента одновременно, максимум два конкурирующих.

### 4.7 Переходы, мемы, эффекты

- Жёсткие склейки. Никаких whoosh-переходов между планами говорящей головы.
- Смена формата (сплит → фуллскрин с чужим видео, смена ракурса) — единственный «спецэффект», и только на смысловом переходе.
- Мемы: данных в пользу нет, крупные клип-каналы их не используют [практика]. Плотность мемов 0 по умолчанию, максимум 1 на ролик: контекстный (спикер сам его упоминает), ≤1,5 с, не поверх лица, без звука-мема.
- Живая реакция человека в кадре работает лучше любого оверлея.
- Запрещено: «смешной» стоп-кадр на неудачном выражении лица спикера, ироническая музыка поверх серьёзного высказывания, кричащие стикеры поверх лица.

### 4.8 Цвет и уникальность

- Порядок цепочки: лёгкая коррекция экспозиции/баланса → творческий LUT → виньетка/зерно → субтитры (строго последними, иначе LUT перекрасит текст).
- Сила LUT регулируется смешиванием с оригиналом: 50–70 % для говорящей головы, иначе кожа уходит в оранжевый.
- Зерно — только по яркости, лёгкое.
- Разные LUT/грейды на соседних роликах — часть уникализации нарезок из одного исходника.
- Двухкамерная запись: согласовать планы по цвету, измеряя кадр (средняя яркость, баланс, насыщенность), а не на глаз.
- Затемнение низа под субтитрами, если используется, — только плавным градиентом: ступенчатые полосы заметны. По умолчанию читаемость держится обводкой.

### 4.9 Технический минимум картинки

- Меньше перекодов — чище картинка: рабочее окно + один финальный энкод.
- Мастер **1440p и выше**: по данным нескольких источников, YouTube даёт ролику 1440p+ кодек VP9 даже без просмотров, а 1080p — AVC, который выглядит мылом [практика]. Загружать H.264.
- Рекомендованные битрейты загрузки: 1440p30 — около 16 Мбит/с, 2160p30 — 35–45 Мбит/с [практика]. После рендера проверять разрешение и битрейт.
- Границы сегментов — на сетке кадров; врезки с другим fps приводить к fps ролика до склейки. Контроль: ожидаемая и фактическая длительность совпадают до одного-двух кадров, иначе субтитры и звуковые события уедут.
- Рез — только между словами, по пословным таймкодам транскрипта.

## 5. Субтитры

### 5.1 Режим

- **Вертикаль — пословно или короткими чанками 1–5 слов.** Консенсус практики — короткие чанки с одним цветом акцента; «каждое слово отдельным кадром» данными не подтверждено [практика]. Выбор — в профиле канала.
- **Горизонталь — фразой, в нижней трети, максимум две строки.** В лонге зритель смотрит со звуком по 10 минут: пословное мигание превращается в дёрганый шум, а крупный текст закрывает говорящего.
- Данные «большинство смотрит без звука» старые и с других платформ; для Shorts (звук по умолчанию включён) это экстраполяция [практика]. Автосубтитры YouTube — «качество может варьироваться», официальной позиции по прожигу против CC нет [офиц.].

### 5.2 Стиль

| Параметр | Вертикаль (1080×1920) | Горизонталь (1920×1080) |
|---|---|---|
| Кегль | ~96 [ориентир] | ~54 [ориентир] |
| Шрифт | жирный гротеск | тот же |
| Цвет | белый, чёрная обводка 6–8 px | белый, обводка/тень |
| Регистр | как в речи (сплошной капс — только если это бренд канала) | как в речи |
| Акцент | один цвет, **не чаще 1 на 5–6 слов**, 0–2 на чанк, повторы не подсвечивать | то же |
| Позиция | нижняя треть над UI | нижняя треть |

- Выделение — на реальный пик мысли, а не «радужная» разметка через слово.
- Без градиентов и лишней анимации букв.

### 5.3 Safe area

- Нижние ~320 px вертикального кадра (1920) закрывает интерфейс Shorts — субтитры с отступом снизу ~420 px, по бокам ≥40 px [ориентир].
- Субтитр не закрывает лицо. Если внизу b-roll или плашка — поднять.
- Ничего не перекрывает субтитры: плашки, описание, бренд.
- Плашку-хук на крупном плане не ставить по центру сверху на макушку — выбирать сторону, где нет лица, по кадрам в начале и в конце показа.

### 5.4 Текст субтитров

- **Ноль опечаток.** Транскрипт вычитывается до рендера: ASR-мусор в субтитрах лонга встречается регулярно и заметен.
- Оговорка спикера в субтитрах исправляется на правильный вариант.
- Буква «ё» — везде, где произносится. Числа — цифрами («100 000», «20–25 лет»), дефисы склеены в один токен («что-то», не «что -то»).
- Пунктуация как в речи, вопросительные знаки обязательны.
- Мат и табу — звёздочки в субтитрах + бип в звуке.
- Последнее слово ролика есть в разметке; события не накладываются.
- Слово шире 90 % кадра — уменьшить кегль для этого слова, не переносить.
- Проверка читаемости: кадр, уменьшенный до 400 px ширины, — субтитр, плашка и лицо читаются без зума.
- Субтитры строятся из пословных таймкодов автоматически, вручную — только акценты и плашки. Ручная расстановка сотен событий даёт рассинхрон, видимый только на готовом рендере.

## 6. Звук

### 6.1 Голос первичен

- Голос всегда разборчив и на первом плане. Музыка и SFX — вторичны.
- Нормализация **−14 LUFS**, лимитер **−1 dBTP**.
- Реплики всех спикеров выровнены по громкости (±2 dB): иначе зритель тянется к регулятору.
- Сохранять естественную манеру речи: характерные обороты, смех, паузы для эффекта. Слова-паразиты у топ-клип-каналов местами оставлены намеренно [эксперт]. Режется мычание, затыки, техническая вода — не личность спикера.

### 6.2 Музыка

- «Музыка повышает удержание» — не подтверждено; топ-клип-каналы работают полностью сухими; в опросе большинство зрителей обучающего talking-head предпочитают без музыки [практика/эксперт].
- **Диалог/спор — по умолчанию без музыки.** Живой нахлёст реплик и есть ритм.
- **Shorts-монолог — подложка −18…−22 dB относительно голоса с дакингом** [ориентир]. Громче −18 dB — ошибка. Кандидат на A/B: сухой звук или −24…−26 dB.
- **Лонг — −22…−26 dB и только на швах**: интро, границы глав, CTA, тихо под личную историю. Под плотной аргументацией — тишина. В лонге постоянная подложка утомляет.
- Включение музыки — событие (после хука, на смене формата), а не с 0:00.
- Смена трека — только на смене главы или формата. Никакой комической/иронической музыки поверх серьёзного высказывания.
- **Music-stop перед панчлайном**: дакинг до тишины за ~0,3 с до ударного слова, слово звучит в тишине.
- Если музыка есть — вырез по частотам голоса (~1200–1500 Гц) в подложке [эксперт].
- Источник — только YouTube Audio Library или собственная генерация/синтез с ясной лицензией. Трек «по шазаму из чужих нарезок» — прямой путь к Content ID claim после публикации; на файловых архивах лицензию часто ставит загрузивший, а не правообладатель.

### 6.3 SFX — точечно, на смысл

| Звук | Когда | Когда нельзя |
|---|---|---|
| Тишина / room tone | пауза перед панчлайном, живой спор | — |
| Бип | мат, табу-слово | — |
| Глухой удар (hit) | смена формата, выход финальной цифры | на каждой склейке |
| Whoosh | вылет плашки (1 раз на касание) | на смене плана говорящей головы |
| Riser | перед финальной цифрой в лонге, 1 на ролик | в коротких Shorts не нужен |
| Клик/UI | появление скриншота/сообщения | иначе — нет |

- В шортсе — не больше ~3 SFX на ролик [ориентир].
- Звуки-мемы и «пампы» — никогда.

### 6.4 Мат и бипы

- Мат в новых роликах — вырезать или запикивать; проверять план монтажа до рендера.
- Бип + звёздочки в субтитрах. Табу-слово с бипом в первые секунды может работать как хук [эксперт], но только если оно реально звучит в речи.

## 7. Упаковка

### 7.1 Заголовки

- **Лонг**: один вопрос или число, ≤60 символов, интрига, а не описание [эксперт]. Без @ и хэштегов в заголовке. Вопрос-дилемма в заголовке — рабочий вариант [практика].
- **Shorts**: 2–5 слов ударом (см. 2.4).
- Если имя спикера — поисковый запрос, его стоит ставить в заголовок (например, суффиксом ` | Имя Фамилия`): это поисковый сигнал и попадание в рекомендации рядом с полными выпусками спикера.
- Новый канал без истории матчится по темам — ясные тематические сигналы в заголовке, описании, тегах [YouTube].
- Заголовок и обложка — одно целое: **дополняют, а не повторяют** друг друга [эксперт].
- Обложку и заголовок продумывать до монтажа — они задают обещание, которое монтаж обязан закрыть [эксперт].
- Для серии — одна формула заголовка.

### 7.2 Обложка лонга

Три правила кликабельности:

1. **Текст доминирует.** Главная надпись — не меньше трети ширины кадра. Числа и вопросы работают лучше утверждений («ПОЧЕМУ 95 %», «3 ПРАВИЛА»).
2. **Максимум 2 конкурирующих элемента**: крупное лицо с эмоцией + один большой текстовый блок. Мелкие бренд-элементы (монограмма, уголок) не считаются, но остаются мелкими. Крупные превью на главной подтвердили: меньше — лучше [YouTube].
3. **Один цвет-акцент** сверх базовой палитры канала, по теме ролика. Не третий-четвёртый цвет.

Дальше:
- **Эмоция лица читает тему**, а не дефолтная «уверенность» на всём подряд: провокация → прищур; шок/цифры → поднятые брови, приоткрытый рот; серьёзный вопрос → задумчивость; уверенность → лёгкая усмешка.
- **Соседние обложки визуально различаются**: одежда, образ, эмоция. Одинаковый образ на всех обложках не даёт отличить ролики в ленте подписок и выдаёт, что всё нарезано из одного источника.
- Лицо освещено ярко и прямо; «тёмный фон + мрачный боковой свет» читается скучно. Энергичный фон не спорит с текстом.
- Glance test: обложка читается за долю секунды на маленьком размере [эксперт].
- **Генерация обложки через AI**: прикладывать референс-кадры из самого исходника (2 кадра спикера, 2 кадра собеседника, 1 общий план сцены) с нужной эмоцией; в промпте явно указывать, какой реф кому соответствует. Без рефов модель рисует «похожего» человека. Если нужен один элемент — писать «exactly ONE»: модель рисует всё, что перечислено.
- Рефы между роликами не переиспользовать: образ и эмоция меняются по теме.
- Каждый ролик — новая обложка-креатив, не шаблон с заменой текста.

### 7.3 Превью Shorts

- Обложку в ленте свайпов почти никто не видит — трафик Shorts идёт из ленты [YouTube]. Кастомные обложки Shorts доступны ограниченно (YPP, десктоп) [офиц.]; что они показываются в самой ленте, официально не подтверждено.
- **Обложку-картинку первым кадром Shorts не вклеивать** — она съедает хук.
- Превью выбирается из кадра ролика с эмоцией; удобно заранее пометить такой кадр в первых 0,5–1 с.

### 7.4 Описание

- **Ссылка — первой строкой.** На телефоне видно примерно первые две строки, остальное под «ещё». Ссылка на 180-м символе фактически не видна.
- Вторая строка — мост от темы ролика к тому, куда ведёт ссылка.
- Дальше — главы-таймкоды (лонг), тематический текст, хэштеги в конце.
- Обновляя описание через API: брать полный текст описания из API (инструменты-обёртки часто режут его до нескольких сотен символов — залить такое обратно = потерять хвост) и передавать весь snippet целиком (заголовок, описание, категорию, теги), иначе незаданные поля обнулятся.

### 7.5 Закреплённый комментарий

- Закреп сразу после публикации: 1–2 строки, конкретный вопрос [практика].
- Рабочие форматы: вопрос с двумя сторонами («А или Б? Пишите в комментарии»); цитата оппонента из ролика как контрпозиция; прогноз («через 5 лет… согласен?»); приглашение к личной истории («сколько лет ты потерял на этом? пиши число»); моральная дилемма из разговора.
- «Третий пункт — в комментариях» — только если он там реально есть.
- Не использовать: намеренные ошибки «чтобы поправили», оскорбление конкретного собеседника, вопросы про внешность, rage-bait — он даёт просмотры без подписок и переходов.
- Комментарии как сигнал вторичны по сравнению с удержанием [YouTube].

### 7.6 Shorts: ссылки не кликаются

- Ссылки в описании и комментариях Shorts не кликабельны. Внешнюю ссылку в закреп шортса не ставить — закреп ведёт на лонг («полный разбор — по ссылке над названием ролика»).
- **Связанное видео (related video) в Studio у каждого шортса обязательно** — это единственный кликабельный мост в лонг.

### 7.7 Главы-таймкоды

- Первый таймкод 00:00, минимум 3 главы, каждая ≥10 с [офиц.]. Эффект на рекомендации официально не заявлен — это навигация и структура.
- Главы = смысловые блоки монтажа (3–6 на лонг).

## 8. Алгоритм YouTube и метрики

### 8.1 Что известно из официальных источников

- **Рекомендации — pull, не push.** Лента собирается под конкретного зрителя в момент открытия; время суток и устройство — сигналы [YouTube].
- Сигналы: история просмотров/поиска, подписки, лайки/дизлайки, «не интересно», **опросы удовлетворённости** [офиц.]. В зачёт идёт «ценное» время просмотра — то, которое зритель оценил бы на 4–5 из 5 [офиц.].
- **Оценивается видео, а не канал.** Слабый прошлый ролик не тянет следующий; штрафа за перерыв нет [YouTube].
- **Ни одна метрика сама по себе не показатель ценности** [YouTube].
- Разные поверхности — разные сигналы: главная опирается на историю, «следующее видео» — на текущий ролик [офиц.].
- **Подписка слабее, чем кажется**: CTR в ленте подписок обычно ≤10 %, и большую часть времени подписчики не выбирают даже лучшие ролики [YouTube]. Уведомления — исключение (opt-in), до 3 в сутки на канал [офиц.].
- Решение не принимается по первой тысяче зрителей; подписчики и новые зрители оцениваются отдельно [YouTube]. Одно видео могут показать зрителю несколько раз, кликают не с первого показа.
- Многие ролики набирают основное через месяц и позже; длинные видео часто смотрят позже, на ТВ [YouTube].
- Разные темы имеют разный потолок просмотров; новое направление оценивать серией из 3–5 роликов, а не одним [YouTube].
- **Shorts**: платформа смотрит на «просмотр vs свайп», AVD, пересмотры и кривые удержания — выше лайков и репостов [YouTube]. Ролики разной длины обрабатываются раздельно.
- Просмотр считается с первого кадра во всех форматах, но **CTR, AVD и удержание — по engaged views**; петли engaged views не увеличивают [офиц.].
- Шортсы не «сбивают» алгоритм для лонгов: система различает форматы и показывает каждому зрителю то, что он смотрит [YouTube].

### 8.2 Официально опровергнутые мифы

| Миф | Ответ |
|---|---|
| Канал штрафуют за слабое видео | оценивается каждое видео отдельно [YouTube] |
| Есть «штрафбокс» за перерыв | нет [YouTube] |
| Shorts вредят лонгам | мост Shorts → лонги существует [YouTube] |
| Есть правильная частота | «магической частоты нет» [YouTube] |
| Есть правильная длина | длину определяют аудитория и устройство [YouTube] |
| Подписчики видят всё | CTR у подписчиков ≤10 % [YouTube] |
| Побеждает CTR | A/B-тест обложек выбирает по доле watch time [офиц.] |
| Обложка решает для Shorts | почти весь трафик Shorts — из ленты [YouTube] |

Не подтверждено официально (не использовать как факт): пороги удержания Shorts («70 %», «80 % за 3 с»), «сид-аудитория из 200 зрителей», «формальное разделение Shorts и лонгов».

### 8.3 Частота

- Минимум 1 ролик в неделю; повышать частоту, только не теряя качества; ежедневность — не требование [практика]. Причинность «чаще = рост» не доказана.
- Залп из нескольких роликов за день-два и дубли темы в один день конкурируют за один и тот же стартовый показ — часть роликов не получает показов вовсе [практика].
- Не судить ролик по первым часам и не перезаливать при слабом старте.

### 8.4 Метрики: что значит и что тестировать дальше

**Shorts**

| Метрика | Что значит | Следующий тест |
|---|---|---|
| Viewed vs swiped away (Stayed to watch) | первый кадр + первое слово | тип первого кадра |
| Engaged views | реальные просмотры | — |
| AVD/APV относительно роликов своей длины | середина и payoff | payoff на 60 % vs 80 %; длина |
| Пересмотр в начале (ratio >1) | хук хочется переслушать | повторить тип хука |
| Shares | «переслать другу» | тезис-обобщение |
| Comments | поляризация | закреп с контрпозицией |
| Subscribers gained | доверие, серия | длина CTA «подпишись» |

**Лонги**

| Метрика | Что значит | Следующий тест |
|---|---|---|
| CTR показов | обещание обложки + заголовка | A/B обложек; число vs вопрос |
| Intro (осталось через 30 с) | хук выполнил обещание | тип хука |
| AVD/APV | структура держит | убрать главу без функции; сократить CTA |
| Spikes | пересмотр/шеринг (интерес или непонятность) | вынести момент в шортс |
| Dips | пропуск или уход: вода, повтор, реклама | вырезать отрезок, сравнить с типичной кривой |
| Traffic source | откуда пришли | нет трафика из related — темы шортсов и лонга не совпадают |
| Returning viewers | серия работает | одна формула заголовка на серию |

- Отчёт Key moments (Intro/spikes/dips) требует ролик ≥60 с и ≥100 просмотров, данные через 1–2 дня; сравнение идёт с последними роликами похожей длины [офиц.]. Для Shorts короче минуты он недоступен.
- CTR в источнике «Подписки» — «чистый» тест упаковки: аудитория там не меняется, удобно сравнивать обложки и заголовки между роликами [YouTube].
- Зрители делятся на новых, случайных (1–5 месяцев в году) и постоянных [офиц.].
- Ключевые данные Studio (свайпы, Intro, показы) через API часто недоступны — снимать вручную.

### 8.5 Когда смотреть и как делать выводы

- Пороги «сильного» ролика считать **по своим данным**, пересчитывать раз в месяц. Чужие бенчмарки не переносить.
- Еженедельный цикл [эксперт]: таблица всех роликов недели → 2 лучших и 2 худших → одна причина на каждый (формат, хук, длина, звук) → одна переменная на следующую неделю. Цель — +1–2 п.п. удержания в месяц на кластер.
- На кривой найти секунду падения и вырезать её причину: удаление одной проблемной секунды заметно поднимает удержание [эксперт].
- Старые ролики не удалять: перезапуск обложки и заголовка оправдан, многие ролики набирают просмотры позже [YouTube].

## 9. Чек-лист перед публикацией и red flags

### 9.1 Чек-лист

**Хук**
- [ ] Речь начинается на кадре 0; нет обложки-картинки, логотипа, приветствия.
- [ ] Первое слово — триггер (вопрос, цифра, клеймо, отказ, табу).
- [ ] Плашка-хук ≤5 слов и дословно совпадает с речью в 0–2,5 с.
- [ ] Лонг: кадр 0 — крупное лицо; факт до 0:05; обещание структуры до 0:30; сильнейшая реплика до 0:30; ноль самопрезентации до первой ценности.

**Удержание**
- [ ] Нет отрезка >8 с (шортс) / >45 с (лонг) без визуального изменения по смыслу; статика >8 с — микро-зум.
- [ ] Punch-in ≤2 на 60 с, только на цифре/клейме/панчлайне, ≤118 %.
- [ ] Речевой брак вырезан; паузы перед ударом оставлены.
- [ ] Шортс: payoff на 55–80 % и в последних 8–10 с. Лонг: re-hook каждые 60–90 с.

**История**
- [ ] Ни один сегмент не начинается с середины мысли; связки «но/поэтому».
- [ ] Реплика собеседника слышна и видна целиком; реакция слушающего после заявления.
- [ ] Обещание заголовка закрыто — таймкод записан.

**Звук**
- [ ] −14 LUFS, −1 dBTP; спикеры выровнены ±2 dB; врезки выровнены отдельно.
- [ ] Музыка не громче −18 dB относительно голоса (лонг — −22…−26 и только на швах); не с 0:00 на диалоге.
- [ ] Music-stop перед панчлайном; SFX ≤3 (шортс); нет whoosh на склейках.
- [ ] Мат запикан, в субтитрах — звёздочки.

**Субтитры**
- [ ] Транскрипт вычитан: 0 опечаток, ё, числа цифрами, дефисы склеены.
- [ ] Акцент ≤1 на 5–6 слов, повторы не подсвечены.
- [ ] Ничего не перекрывает субтитры; safe area соблюдена; читается на 400 px.

**Визуал**
- [ ] Кроп на говорящем по всем сегментам (лист кадров проверен); лицо ~40 % высоты, глаза на 35–40 % от верха.
- [ ] Плашки-тезисы ≤1 на 60–90 с лонга; в шортсе — хук + ≤1.
- [ ] Не больше двух конкурирующих элементов в кадре.
- [ ] B-roll ≤~4 на минуту, только буквальный.

**CTA**
- [ ] Шортс: CTA «подпишись» ≤1,5 с после последнего слова.
- [ ] Лонг: мягкий CTA ≤15 с в шве; полный ≤30 с в конце; ни одного рекламного блока >30 с в середине.
- [ ] Лонг: конечная заставка 5–20 с настроена в Studio.

**Упаковка**
- [ ] Заголовок: шортс 2–5 слов, лонг ≤60 символов; без @; хэштеги в хвосте.
- [ ] Описание: ссылка первой строкой, вторая — мост; главы с 00:00 (лонг).
- [ ] Закреп написан; у шортса — связанное видео в Studio, без внешней ссылки.
- [ ] Обложка лонга: текст ≥⅓ ширины, 2 элемента, 1 акцент, эмоция под тему, отличается от соседних.

**Права и техника**
- [ ] Музыка — библиотека YouTube или собственная с ясной лицензией.
- [ ] Чужое видео — короткий фрагмент с комментарием/реакцией спикера, без чужой звуковой дорожки там, где риск Content ID высок.
- [ ] Исходники не изменены; временные файлы — в отдельной папке.
- [ ] Разрешение и битрейт проверены; ожидаемая длительность = фактической (±1–2 кадра); стыки без выпавших кадров.

### 9.2 Шкала качества (опционально)

13 критериев по 0–10: Hook, Promise fulfilled, Clarity, Pacing, Curiosity, Emotion, Visual variety, Audio, Captions, Payoff, Rewatchability, Commentability, Brand & CTA. Сумма нормируется к 100. Порог публикации — 75 [ориентир]. Ниже 6 из 10 по Hook, Captions или Promise — не публиковать, откатить на нужную стадию.

### 9.3 Red flags — не делать

1. Обложка-картинка первым кадром Shorts.
2. Приветствие или «в этом видео» в первые 5 с.
3. Самопрезентация до первой ценности.
4. Плашка-хук, не совпадающая с первой фразой.
5. Сильный тезис на 15-й секунде, а до него вода.
6. Статичный план >45 с в лонге / >8 с в шортсе без смысловой причины.
7. Зум/whoosh по таймеру «каждые 2 секунды».
8. Punch-in >120 % или больше двух на минуту; глаза прыгают при смене крупности.
9. Камера на слушающем, пока говорит собеседник, дольше ~2 с.
10. Реакция группы слышна, но не показана.
11. Мычание и затыки в речи и субтитрах.
12. Оговорка спикера или ASR-мусор в субтитрах.
13. Субтитры без «ё», с разорванными дефисами.
14. Акцентное слово каждое третье.
15. Субтитры под описанием или плашкой.
16. Сплошной капс, если это не бренд канала.
17. Музыка с 0:00 на диалоге; музыка громче −18 dB относительно голоса.
18. SFX на каждой склейке.
19. Ироническая музыка или «смешной» стоп-кадр на спикере.
20. Мем-оверлей поверх лица; звуки-мемы.
21. Стоковый b-roll «для заполнения».
22. Рекламный блок >30 с в середине лонга.
23. CTA-баннер на 2 с с мелким текстом.
24. CTA «подпишись» дольше 1,5 с или поверх последнего слова.
25. Обрыв на полуслове в конце.
26. Payoff в первой трети шортса.
27. Обещание заголовка не закрыто в ролике.
28. @-упоминания и хэштеги внутри заголовка.
29. Несколько роликов одной темы в один день.
30. Rage-bait на внешности собеседника.
31. Чужой трек (особенно в Short длиннее минуты).
32. Внешняя ссылка в закрепе шортса вместо связанного видео.
33. Одинаковый образ спикера на соседних обложках.
34. Лонг без настроенной конечной заставки.

## 10. Эксперименты

### 10.1 Правила

- **Один ролик — одна переменная.** Всё остальное — как в контроле.
- Где возможно — пара роликов из **одного исходного момента** (два монтажа одного куска).
- Публикация в одно и то же окно времени; оценка через 7 дней.
- Сравнивать только с роликами своей длины и своего формата.
- Тему оценивать серией (3–5 роликов), а не одним роликом.
- Победившую переменную закреплять в профиле канала, а не держать в голове.

### 10.2 A/B превью в Studio

- До 3 вариантов заголовка/обложки; победитель выбирается по **доле watch time, а не по CTR**; тест идёт до 2 недель; работает только на десктопе и **недоступен для Shorts** [офиц.].
- Готовить 3 варианта обложки лонга, различающиеся одной вещью (число vs клеймо, эмоция A vs эмоция B).
- Если обложка не идёт — менять быстро [эксперт].

### 10.3 Банк гипотез

| Гипотеза | Переменная | Метрика |
|---|---|---|
| Реплика собеседника первым кадром держит лучше цифры-плашки | тип первого кадра | viewed vs swiped, пересмотр 0–3 с |
| 55–65 с с эскалацией лучше 30–35 с одной реплики | длина | APV своей длины, просмотры |
| Сухой звук на диалоге лучше подложки −22 dB | музыка | APV |
| Заголовок-клеймо 2–5 слов лучше вопроса | заголовок | просмотры |
| Реакция слушающего после заявления поднимает середину | реакции | APV середины |
| Punch-in на панчлайне даёт пересмотр финала | punch-in | пересмотр в конце |
| Music-stop перед панчлайном | music-stop | пересмотр, комментарии с цитатой |
| CTA «подпишись» 1,5 с против 3 с | длина CTA | последние 5 % кривой, подписки |
| Redacted pull-forward лучше линейного старта | хук | свайпы, APV |
| Цифра крупно в кадре лучше обычного акцента | графика | пересмотр на цифре |
| Лонг: хук-факт против хук-реплики | хук | Intro 30 с |
| Лонг: мягкий CTA ≤15 с против 60 с | длина CTA | провал на врезке |
| Лонг: плашки-тезисы на главах против без | графика | APV, провалы |
| Горизонтальный клип 1–3 мин против Shorts того же момента | формат | подписки на просмотр, переходы в лонг |
| Лонг вечером против утра | время выхода | просмотры за 7 дней |

## 11. Что автоматизировать, а что нет

| Задача | Режим |
|---|---|
| Анализ исходника, вырезка окон, рендер | автоматически |
| Транскрипция с пословными таймкодами | автоматически |
| Вычитка транскрипта | LLM правит, человек утверждает спорное |
| Детект лица, активного говорящего, траектория кропа | автоматически + лист кадров на проверку |
| Удаление тишины и мычания | кандидаты автоматически, решение — человек (паузы перед ударом) |
| Поиск моментов | LLM предлагает, человек выбирает |
| Хук, порядок реплик, место payoff | человек (с помощью LLM) |
| Punch-in, реакции, смена формата | решение — редактор, исполнение — автоматически |
| Субтитры | генерация автоматически, акценты — редактор |
| Нормализация, дакинг | автоматически |
| Технический QC | автоматически |
| Редакторский QC (шкала) | человек |
| Заголовок, закреп, обложка | варианты — LLM, выбор — человек |
| Аналитика | сбор автоматически, выводы — человек |

Не автоматизировать до конца: выбор момента, хук, порядок реплик, акценты, решение о музыке — там качество падает первым.

## Приложение. Что показали кривые удержания на практике

Наблюдения по лонгам одного разговорного канала (споры и разборы). Выборка маленькая —
это **гипотезы для проверки на своём канале**, а не правила. Сверяйте с собственной
аналитикой и записывайте выводы в `channel/profile.md`.

| Наблюдение | Что делать |
|---|---|
