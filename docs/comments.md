# Комментарии: ответы и модерация

Ответ канала в залайканной ветке видят все, кто её читает, — это охват и второй вход
в воронку. А грубость под роликами YouTube придерживает на проверку, и без разбора
очередь копится. Обе задачи закрывает `scripts/community/comments.py` и команда `/comments`.

## Ответы

```
/comments
```

1. `comments.py fetch` выгружает ветки за последние 7 дней, на которые канал ещё не
   ответил, — самые залайканные и обсуждаемые сверху (`community/inbox_<дата>.md`).
2. Агент `community-manager` пишет черновики тоном вашего канала: часть — просто ответ,
   часть — с прогревом на другой ваш ролик, часть — с байтом на оффер (не больше трети).
3. Вы читаете `community/replies_<дата>.md`, говорите, что одобрить и что поправить.
4. Одобренные публикуются по API — или копируете руками, если OAuth не настроен.

Для выгрузки хватает API-ключа из `/setup-channel`. Для публикации нужен OAuth.

## Модерация

```bash
python scripts/community/comments.py moderate           # показать решения
python scripts/community/comments.py moderate --apply   # применить
python scripts/community/comments.py test               # сверить правила с ручным журналом
```

Правила — `channel/comment-rules.json` (образец — `comment-rules.example.json`):

- `reject` — категории и шаблоны (регулярные выражения по корню слова): оскорбления,
  сексуальные комментарии, угрозы, этнические оскорбления, спам;
- `allow` — слова-исключения, в которых корень совпал случайно («сосед»);
- `reject_foreign_links` + `own_links` — чужие ссылки скрываются, свои остаются.

Всё, что не попало под `reject`, публикуется: шутки, мат без оскорбления, критика канала.
Скрипт разбирает очередь «на проверке» и заодно последние опубликованные комментарии —
прямое оскорбление, которое фильтр YouTube пропустил, тоже скрывается. Каждое решение
пишется в `community/moderation_log.jsonl`; если вы решали что-то руками, добавьте строку
с `"by": "manual"` — команда `test` покажет, где правила расходятся с вами.

### По расписанию

Windows (каждые 30 минут):

```
schtasks /Create /TN "Narezchik comments" /SC MINUTE /MO 30 /F /TR "\"<python.exe>\" \"<папка>\scripts\community\comments.py\" moderate --apply"
schtasks /Delete /TN "Narezchik comments" /F
```

Linux/macOS (cron): `*/30 * * * * cd <папка> && python3 scripts/community/comments.py moderate --apply`

Сначала неделю погоняйте без `--apply` и посмотрите решения.

## OAuth

Тот же, что для загрузки роликов, — `docs/publish.md`, шаги 1–4
(`python scripts/publish/youtube_upload.py --auth`). В правах запрашивается
`youtube.force-ssl` — без него YouTube не даёт отвечать и модерировать. Если токен
получен раньше, пройдите `--auth` заново.

## Квота

Просмотр — 1 единица за страницу, скрытие/публикация пачки до 50 комментариев — 50,
один ответ — 50. При лимите 10 000 в сутки это до ~150 ответов в день, если больше
ничего не грузить; загрузка ролика стоит ~1600.
