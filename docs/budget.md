# Работа на подписке Claude Pro ($20/мес)

Нарезчик рассчитан на то, чтобы Pro хватало на регулярный выпуск роликов. Точных цифр
лимитов Anthropic не публикует, и они меняются, поэтому здесь — не обещание «N роликов в
месяц», а то, как устроена экономия и что делать вам.

## Как устроены лимиты

- Лимит общий для всех моделей и всех сабагентов: окно около 5 часов плюс недельный лимит.
  Переключение модели исчерпанный лимит не возвращает.
- Каждый сабагент — отдельный контекст, но его токены идут в тот же лимит.
- Расход зависит от модели: Haiku тратит лимит заметно медленнее Sonnet, Sonnet —
  медленнее Opus.
- Сколько осталось — команда `/usage` в Claude Code.

## Что уже сделано в репозитории

| Решение | Почему экономит |
|---|---|
| Модель проекта по умолчанию — Sonnet (`.claude/settings.json`) | Opus на Pro сжигает окно за несколько больших задач |
| Техник (`render-engineer`) на Haiku | запуск скриптов и чтение логов не требует сильной модели |
| Режим `budget: "eco"` по умолчанию | один агент на стадию для всех роликов, без b-roll-поиска, один круг критики |
| Транскрипт целиком читает только скаут, и то компактный `.txt` | пословный JSON часового подкаста — сотни тысяч токенов |
| `transcript_window.py` | остальные агенты берут только свой диапазон |
| `auto_cut.py`, `build_subtitles.py`, `autoframe.py` | нарезка по паузам, субтитры и кроп — код, а не модель |
| Лист кадров вместо десятков скриншотов | одна картинка вместо десяти |
| Короткий CLAUDE.md, подробности в `docs/` | CLAUDE.md грузится в каждую сессию |
| Профиль канала 80–150 строк | его читает каждый агент на каждом запуске |

## Что делать вам

1. **`/clear` между пачками.** Закончили ролики из одного видео — `/clear` и следующее.
   Старый контекст оплачивается на каждом сообщении.
2. **Подтверждайте кандидатов до монтажа.** Скаут показывает таблицу моментов — уберите
   лишние сразу. Каждый смонтированный и отброшенный ролик — потерянный лимит.
3. **Правки — словами и сразу по делу:** `/fix podcast_short03 хук длинный, начни с «Никогда»`
   дешевле, чем «переделай, что-то не то».
4. **Не просите пересказывать файлы.** Отчёты агентов короткие специально; подробности —
   в самих планах и `edit-plans/*_ПУБЛИКАЦИЯ.md`.
5. **Отключите ненужные MCP-серверы** (`/mcp`): их описания грузятся в каждый запрос.
6. **Транскрипция и рендер лимит не тратят** — это локальные программы. Долгие задачи
   запускайте и уходите: Claude не должен «ждать» их, опрашивая каждую минуту.
7. Упёрлись в лимит посреди пачки — ничего не потеряно: всё состояние в `edit-plans/`.
   После сброса окна скажите «продолжи /shorts по podcast12» — продюсер найдёт планы по
   `project.stage` и продолжит с того же шага.

## Сколько стоит ролик

Замер на живом прогоне (двухчасовой подкаст, 2 шортса, все стадии на Sonnet, техник на
Haiku), в ценах API — на подписке это расход лимита, а не денег, но пропорции те же:

| Стадия | На 2 ролика |
|---|---|
| Приём исходника | $0,07 |
| Скаут (читает весь транскрипт) | $0,78 |
| Сценарист | $0,78 |
| Монтажёр | $2,41 |
| Рендер и техконтроль | $0,31 |
| Критик | $0,65 |
| Упаковщик | $0,59 |
| **Итого** | **$5,59**, около $2,8 за ролик |

Самая дорогая стадия — монтажёр: он смотрит кадры. Скаут стоит одинаково, сколько бы
роликов вы ни взяли из исходника, поэтому 5 шортсов из одного подкаста выгоднее, чем
по одному из пяти. Круг правок после критика добавляет примерно треть стоимости ролика.

## Режимы (`channel/settings.json` → `budget`)

| | `eco` (Pro) | `standard` (Max) | `max` |
|---|---|---|---|
| Агенты | один на стадию, все ролики подряд | один на стадию | агент на каждый ролик, параллельно |
| B-roll-поиск | нет | да | да |
| Кругов критики | 1 | 2 | 3 |
| Упаковка | по запросу | всегда | всегда |

Хочется сильнее модель на конкретной роли — поменяйте `model:` в `.claude/agents/<роль>.md`
(например, `packager` на `opus` для заголовков), остальное оставьте как есть.
