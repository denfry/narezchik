# Подключение канала: `/setup-channel`

Команда подстраивает весь воркфлоу под ваш канал: выгружает статистику роликов,
смотрит, что у вас уже заходит, и пишет профиль, по которому работают все агенты.

## Что понадобится

1. Установленный репозиторий (`install.cmd` / `./install.sh`, компонент `channel` —
   он ставит yt-dlp для субтитров лучших роликов).
2. **YouTube Data API ключ** — бесплатно, 3–5 минут. Нужен только для чтения публичных
   данных канала (заголовки, просмотры, длительность, обложки). Доступа к аккаунту он
   не даёт и ничего не публикует.

## Как получить API-ключ

1. Откройте https://console.cloud.google.com/ и войдите любым Google-аккаунтом.
2. Сверху — выпадающий список проектов → **New Project** → любое имя → Create.
3. Меню → **APIs & Services → Library** → найдите **YouTube Data API v3** → **Enable**.
4. **APIs & Services → Credentials → Create credentials → API key**. Скопируйте ключ.
5. (Рекомендуется) там же **Edit API key → API restrictions → Restrict key →
   YouTube Data API v3** — ключ не сработает ни для чего другого, если утечёт.

Если у вас уже настроен OAuth для загрузки роликов (`secrets/token.json`, docs/publish.md),
отдельный ключ не нужен — скрипты возьмут токен.

Ключ можно дать Claude в чате (он сохранит его в `secrets/youtube_api_key.txt` — папка
не попадает в git) или положить туда самим, или задать переменную окружения
`YOUTUBE_API_KEY`. Квота — 10 000 единиц в сутки; разбор канала на 250 роликов тратит
около 10.

## Что происходит

```
/setup-channel @ваш_канал
```

1. Проверка окружения (`install.py --check`).
2. `scripts/channel/analyze_channel.py` выгружает до 250 последних роликов в
   `channel/analysis/`: `summary.md` (сводка), `videos.json` (все данные),
   `thumbs_top.jpg` / `thumbs_recent.jpg` (сетки обложек), `transcripts/` (субтитры
   5 лучших роликов — как говорит спикер и чем открываются удачные ролики).
3. Claude задаёт до шести вопросов: ниша и спикеры, форматы, воронка, стиль, что нельзя,
   какая у вас подписка.
4. Агент `channel-analyst` пишет:
   - `channel/profile.md` — что работает на канале, стиль монтажа, упаковка, воронка;
   - `channel/brand.json` — цвет-акцент (по вашим обложкам), монограмма, тексты плашек;
   - `channel/content-rules.md` — что не брать никогда и о чём спрашивать;
   - `channel/settings.json` — режим экономии, сколько шортсов из исходника, слоты публикаций.
5. Вы смотрите выжимку и картинку-плашку, правите словами — Claude вносит в файлы.

Все четыре файла — обычный текст/JSON, их можно править руками в любой момент.
Перезапуск `/setup-channel` через месяц обновит профиль по свежей статистике.

## Если канала ещё нет

Скажите об этом — шаг выгрузки пропустится, профиль соберётся по вашим ответам и общим
правилам `docs/playbook.md`. Через 15–20 роликов стоит запустить команду снова.

## Запуск вручную

```bash
python scripts/channel/analyze_channel.py @handle --max 250 --transcripts 5 --utc-offset 3
python scripts/channel/analyze_channel.py https://www.youtube.com/@handle --no-shorts-check
```

Ролики до 60 с считаются Shorts; 61–180 с проверяются запросом к `youtube.com/shorts/<id>`
(с октября 2024 Shorts бывают до 3 минут). `--no-shorts-check` отключает проверку.
