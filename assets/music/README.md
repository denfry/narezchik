# Музыка

Сюда кладутся `.mp3`/`.wav`, которые подмешиваются под голос. Пайплайн сам треки не
скачивает: лицензия — юридическое решение, а не техническое. Файлы в git не попадают,
кроме этого реестра.

Установщик кладёт сюда три синтезированные подложки (`dark_drone_01`, `tense_pulse_01`,
`soft_air_01`) — простые, но без чужих прав. Для нормального звучания добавьте свои треки.

## Что нужно

3–5 треков под характеры канала: тёмный кинематографичный бит (провокация, спор),
напряжённый пульс (нарастание перед панчлайном), минималистичное фортепиано (серьёзный
разговор, личная история).

Требования: без вокала (вокал спорит с речью), от 60 секунд, без резких пиков и смены
темпа — под дакингом это читается как сбой громкости.

## Где брать без отчислений

- **YouTube Audio Library** (в YouTube Studio) — безопаснее всего по Content ID.
- **Pixabay Music** — без указания автора.
- **Mixkit** — Mixkit Stock Music Free License.
- **Uppbeat** — бесплатный тариф, требует указания трека в описании.
- **Локальная генерация ACE-Step** — `scripts/pipeline/gen_music.py`, см. docs/music.md.

Файлы с «бесплатных» агрегаторов проверяйте: лицензию там часто проставляет загрузивший,
а не автор, и claim по Content ID прилетает уже после публикации.

## Как назвать

По характеру, а не по названию трека: `dark_beat_01.mp3`, `tense_pulse_02.mp3`,
`piano_min_01.mp3` — так агент выбирает по смыслу, не открывая каждый файл.

## Реестр (файл | источник | лицензия | дата) — одна строка на трек

Без записи через месяц невозможно доказать право на использование.
