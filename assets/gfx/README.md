# Фоны карточек и плашек

`scripts/pipeline/make_cards.py` рисует полноэкранные карточки лонга (раунды, счёт,
пруфы, вопрос зрителю, топ-N, конечная заставка) и плашки. Без своих фонов он рисует
запасной — тёмный градиент с отсветом цвета акцента из `channel/brand.json`. Этого
достаточно, чтобы начать; фирменные фоны делают ролики узнаваемее.

Фоны — **без текста**: текст кладёт скрипт фирменным шрифтом (одна ошибка в русском
слове на сгенерированной картинке портит кадр). У каждой картинки нужна тихая зона под текст.

| Файл | Размер | Для чего |
|---|---|---|
| `bg_round_{a,b}.jpg` | 3840×2160 | заставка раунда / пункта «РАУНД N / ТЕМА» |
| `bg_score_final_{a,b}.jpg` | 3840×2160 | финальное табло со счётом |
| `bg_proof_{a,b}.jpg` | 3840×2160 | карточка-пруф: крупная цифра и источник |
| `bg_question_{a,b}.jpg` | 3840×2160 | вопрос зрителю, итоговый список |
| `bg_tail_{a,b}.jpg` | 3840×2160 | конечная заставка (середина пустая под элементы YouTube) |
| `tex_steel_{a,b}.png` | 4096×1024 | заливка плашек и табло |
| `tex_red_{a,b}.png` | 4096×1024 | акцентная заливка, ячейка лидера |

Варианты `_a` / `_b` чередуются у соседних карточек. Сгенерировать можно любой
AI-моделью по промпту вида «dark cinematic studio background, <цвет акцента> light rays
from the bottom, empty center area for text, no text, no letters, 16:9» — и проверить,
что на картинке действительно нет букв.
