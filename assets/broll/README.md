# B-roll

Видео и картинки для иллюстраций внутри роликов. Агент-монтажёр (skill
`broll-researcher`) решает, где врезка оправдана, и оставляет в плане `search_query`,
если файла нет. Вы находите/генерируете файл, кладёте сюда и называете понятно
(`money_stack_closeup.mp4`), агент подставляет путь в `assets[]`.

Правило: не больше ~4 врезок на минуту речи и только там, где сказанное можно показать
буквально (вещь, цифра, место, действие). Лицензию каждого файла записывайте ниже.
