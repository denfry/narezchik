# Нарезчик — автоматизация нарезок на Claude Code

Общение с пользователем — на русском. Этот файл грузится в каждую сессию: он короткий
намеренно, подробности — в `docs/`.

## Что это

Из длинного видео (подкаст, интервью, стрим, монолог) командой агентов делаются готовые
Shorts и лонги 5–15 мин под стиль конкретного канала. Главная сессия — **продюсер**:
раздаёт задачи агентам через команды и сама не монтирует.

| Команда | Что делает |
|---|---|
| `/setup-channel [@канал]` | подключить канал по YouTube API, собрать профиль стиля |
| `/ideas [источник]` | моменты и темы / контент-план |
| `/shorts <видео> [N]` | N готовых Shorts |
| `/long <видео \| сценарий>` | лонг 5–15 мин |
| `/fix <clip_id> <что не так>` | точечная правка |
| `/pack <clip_id \| префикс> [дата]` | упаковка, расписание, загрузка |
| `/comments` | ответы на комментарии, модерация |

Агенты (`.claude/agents/`): `channel-analyst`, `idea-scout`, `scriptwriter`,
`shorts-editor`, `long-editor`, `render-engineer`, `qc-critic`, `packager`,
`community-manager` — роли и конвейер в
`docs/agents.md`.

## Где что

- `channel/` — профиль канала: `profile.md` (стиль, что работает), `brand.json` (цвета,
  монограмма, плашки), `content-rules.md` (что нельзя), `settings.json` (бюджет, частота).
  **Правила канала главнее общих.** Нет профиля — предложить `/setup-channel`.
- `docs/playbook.md` — общий учебник монтажа и упаковки.
- `edit-plans/<clip_id>*.json` — план монтажа, единственный канал состояния между агентами
  (`project.stage`). Схема — `schemas/edit-plan.schema.json`, описание — `docs/pipeline.md`.
- `input/` исходники (только читать), `transcripts/`, `temp/` (временное), `output/` готовое,
  `ideas/` идеи и планы, `cta/` материалы для врезок, `assets/` шрифты/LUT/музыка/b-roll.
- `scripts/pipeline/` рендер-ядро и утилиты, `scripts/channel/` разбор канала,
  `scripts/publish/` публикация, `scripts/community/` комментарии, `scripts/remote/` свой сервер.

## Правила, которые нельзя нарушать

- Никогда не приписывать спикеру слов, которых нет в транскрипте. Перестановки не должны
  менять смысл сказанного.
- `channel/content-rules.md`: «стоп» — не брать никогда; новая категория риска — файл
  `edit-plans/<clip_id>_⚠️ТРЕБУЕТ_РЕШЕНИЯ.md` с цитатами и вопрос пользователю.
- `python scripts/pipeline/validate_edit_plan.py <plan>` перед каждым рендером.
- Рендеры и другие тяжёлые задачи — строго по одному; долгие — в фоне, без частых опросов.
- Всё, что уходит на YouTube (`youtube_upload.py` без `--dry-run`, `comments.py ... --apply`), —
  только по явной просьбе и после подтверждения списка пользователем.
- Секреты (`secrets/`, API-ключи) не выводить в ответах и не коммитить.

## Экономия лимита подписки

Проект рассчитан на Claude Pro — `docs/budget.md`. Коротко: транскрипт целиком читает
только скаут и только `.txt`; остальные — `transcript_window.py`; нарезку по паузам,
субтитры и кроп делают скрипты (`auto_cut.py`, `build_subtitles.py`, `autoframe.py`);
агент на стадию, а не на ролик; отчёты короткие; советовать `/clear` между пачками.
