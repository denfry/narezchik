# /comments

## Ответы (по умолчанию)

1. `python scripts/community/comments.py fetch --days 7 --top 40` (в режиме `eco` — `--top 25`).
   Нужен API-ключ и ID канала (есть после `/setup-channel`).
2. Агент `community-manager` — черновики в `community/replies_<дата>.json` и `.md`.
3. Показать пользователю `.md` (или 5–10 примеров) и спросить, что одобрить: «все»,
   «кроме 3 и 7», правки текста. Внести `approved: true` и правки в json.
4. Публикация — **только после явного «да»**:
   `python scripts/community/comments.py post community/replies_<дата>.json` (показ),
   затем с `--apply`. Нет OAuth — инструкция `docs/comments.md`; тогда пользователь
   копирует ответы из `.md` руками.

## Модерация

1. Нет `channel/comment-rules.json` — агент `community-manager` собирает его под канал.
2. `python scripts/community/comments.py moderate` — показать решения, обсудить спорные
   с пользователем, поправить правила.
3. `--apply` — только после подтверждения. Скрытие комментариев видно зрителям как
   исчезновение ветки, откатывается вручную в Studio.
4. По желанию — расписание (Планировщик Windows / cron), команды в `docs/comments.md`.
