# /setup-channel

Ты в главной сессии ведёшь настройку. Тяжёлую аналитику делает агент `channel-analyst`,
данные — скрипт. Общайся с пользователем по-русски и коротко.

## 1. Окружение

`python install.py --check`. Если нет ffmpeg или ядра — предложить `python install.py
--auto` (или `install.cmd` двойным кликом) и дождаться. Без ядра дальше не идти.

## 2. Канал и ключ

- Канал — из аргумента (`$ARGUMENTS`) или спросить: `@handle`, ссылка или ID `UC…`.
- API-ключ: есть ли `YOUTUBE_API_KEY` или `secrets/youtube_api_key.txt`. Нет — дать
  инструкцию из `docs/setup-channel.md` (Google Cloud → YouTube Data API v3 → API key,
  3 минуты, бесплатно) и попросить вставить ключ. Сохранить в
  `secrets/youtube_api_key.txt` (папка в .gitignore). Ключ никуда больше не писать и
  в ответах не повторять.
- Нет канала (новый, 0 роликов) — пропустить шаг 3, профиль строится по ответам
  и `docs/playbook.md`.

## 3. Выгрузка

```
python scripts/channel/analyze_channel.py <канал> --max 250 --transcripts 5
```

`--transcripts` работает, если стоит yt-dlp (компонент `channel` установщика). Прочитать
`channel/analysis/summary.md` самому только бегло — подробно его читает аналитик.

## 4. Вопросы пользователю (одним сообщением, AskUserQuestion где уместно)

Не больше 6, пропуская то, что уже ясно из данных:
1. Ниша и кто спикеры (имена для подписей и словарь терминов/имён, которые ASR путает).
2. Что делаем: только Shorts / только лонги / оба; сколько в неделю.
3. Воронка: куда вести зрителя (ссылка); есть ли видео-зазывалка спикера (положить в `cta/`);
   нужны ли **байты**: в Shorts — мост в лонг, в лонгах — заход на оффер в середине ролика.
4. Стиль: спокойный/экспертный или динамичный; музыка — да/нет; мат — пикать/оставлять.
5. Что нельзя: темы, люди, слова (сверх универсальных стоп-правил).
6. Бюджет: подписка Claude Pro ($20) → режим `eco` (по умолчанию) или Max → `standard`.

## 5. Профиль

Запустить агента `channel-analyst` с промптом: путь к analysis, ответы пользователя
дословно, просьба написать 4 файла. После — показать пользователю 5–10 строк выжимки
профиля и картинку `temp/brand_check.png`, спросить «всё верно?». Правки вносить сразу
в файлы.

## 6. Финал

Сообщить, что готово, и следующий шаг: «положите видео в `input/` и скажите
`/shorts input/<файл>` или `/long input/<файл>`». Если в `cta/` пусто, а воронка есть —
напомнить, что туда класть (см. `cta/README.md`).
