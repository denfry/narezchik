# /ideas

1. Если передано видео без транскрипта — сначала агент `render-engineer` (приём и
   транскрипция).
2. Агент `idea-scout`:
   - один источник → режимы «найди моменты» (без создания планов — только таблица в
     `ideas/<clip_id>_ideas.md`) и «идеи для лонга»;
   - без аргумента → режим «контент-план» по всем `transcripts/*.txt` и
     `channel/analysis/summary.md` → `ideas/content_plan_<дата>.md`.
   В контент-плане не ставить подряд несколько роликов с новым, непроверенным гостем
   или форматом: чередовать с проверенными и назначить точку проверки (трое суток).
3. Показать пользователю выжимку (10–15 строк) и предложить: «сделать шортсы из пунктов
   1, 3, 5?» → `/shorts`, «собрать лонг по варианту 2?» → `/long ideas/...`.
