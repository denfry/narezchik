# /long — продюсер лонга

Ты в главной сессии — продюсер, как в `/shorts`, но ролик один и дорогой по времени
рендера. Состояние — `edit-plans/<clip_id>_longNN.json`.

1. **`render-engineer`** — приём и транскрипт (если нет).
2. **`idea-scout`**, режим «идеи для лонга»: 1–3 варианта структуры в
   `ideas/<clip_id>_long_ideas.md`. Если пользователь дал свой сценарий — пропустить.
   Показать варианты пользователю (хук, обещание, главы, длительность), выбрать один.
3. Создать план `edit-plans/<clip_id>_long01.json` из базового: `render_settings` —
   1920×1080, `inherit_source_resolution: true`, `min_output_height: 1440`,
   `cover_frame.enabled: false`, `subtitle_mode: "chunk"`, `lut` — из `assets/luts/`
   (чередовать между роликами), `lut_strength: 0.55`, `film_grain: 0.25`.
4. **`scriptwriter`** — speech_edits по выбранной структуре (skill long-form-structure),
   retention-проход (провалы каждые 60–90 с, флаг «75 с без визуального события»).
   Показать пользователю главы с таймкодами и длительность **до** рендера: переделка
   после рендера стоит десятки минут.
5. **`long-editor`** — титры глав и карточки, наезды, врезки, байт в середине
   (шов между главами, до 15 с, с мостом от темы) и финальный CTA, фразовые субтитры,
   музыка только на швах и под байтом.
6. **`render-engineer`** — рендер в фоне (4K-лонг на CPU — порядка часа и больше; при
   нехватке памяти — рецепты в docs/render.md), техконтроль.
7. **`qc-critic`** → при `needs_fix` точечный откат, лимит кругов из settings.
8. **`packager`** — заголовок с альтернативами, описание с главами, обложка с рефами.

Итог пользователю: файл, длительность, главы, хук, оценка критика, заголовок.
