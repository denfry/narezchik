# packaging

Упаковка решает, нажмут ли на ролик и перейдут ли по воронке. Монтаж здесь не трогается.
Общие правила — `docs/playbook.md`, раздел «Упаковка»; правила канала — `channel/profile.md`
(«Упаковка», «Воронка») — они главнее.

## Заголовок

- Обещает то, что реально есть в ролике (сверить с `speech_edits[].transcript_text`).
- Формулы, которые обычно работают в разговорных нарезках: вопрос («Почему…?»), число
  («3 правила…»), конфликт («Она сказала X — он ответил»), контринтуитивное утверждение.
  Какие работают **на этом канале** — смотреть `channel/analysis/summary.md`.
- Если в профиле есть фирменный хвост (например ` | Имя Фамилия`) — ставить его всегда.
- Длина ~40–70 символов, главное — в первых 40 (обрезается на телефоне).
- 2–3 альтернативы с другой формулой — для A/B-теста в Studio.

## Описание

1. **Первая строка — ссылка воронки** из профиля, с глаголом («👉 Бесплатный урок: <ссылка>»).
   На телефоне без раскрытия видно около двух строк.
2. Вторая строка — мост от темы ролика к воронке.
3. Дальше 2–4 предложения о ролике с ключевыми словами темы.
4. Лонг — главы `00:00 Название` (первая обязательно 00:00, минимум три, каждая ≥ 10 с).
5. Хэштеги — 3–5 в конце (первые три показываются над заголовком).
Длина и SEO-хвост — по профилю канала.

## Теги

10–20 штук: тема, имена спикеров, синонимы запроса, название канала. Теги слабо влияют
на ранжирование — не тратить на них много сил.

## Закреплённый комментарий

- Лонг: ссылка воронки + вопрос зрителю по теме ролика (провоцирует комментарии).
- Shorts: **ссылки в описании и комментариях Shorts не кликабельны.** Закреп ведёт
  в лонг: «▶ Полный разбор — по ссылке над названием ролика», а в Studio у шортса
  выставляется «Связанное видео» = лонг (`project.related_long`).

## Обложка (лонги; у Shorts — только кадр из ролика)

Три правила: текст — доминирующий элемент (≥ 1/3 ширины, 2–4 слова, число/вопрос лучше
утверждения); максимум два конкурирующих элемента (лицо + текст); один цвет-акцент сверх
бренд-палитры (`channel/brand.json`). Эмоция лица и одежда — под тему ролика; соседние
обложки не должны выглядеть одинаково.

Промпт для AI-генерации пишется **вместе с референс-кадрами** — без них модель рисует
«похожего» человека:

1. 3–5 кадров из исходника: `ffmpeg -ss <T> -i <source> -frames:v 1 -q:v 2
   temp/<clip_id>_refs/ref1_<кто>_<эмоция>.jpg` — лицо крупно, в фокусе, эмоция под тему;
   один общий план студии (держит свет и обстановку). Кадры сверить глазами.
2. В промпте явная строка: `Use the attached reference images: ref1 and ref2 = <описание
   спикера> (keep face and build exactly), ref3 = <гость>, ref4 = the real set and lighting`.
3. Текст обложки — прямо в промпте, кириллицей, в кавычках; бренд-элементы (монограмма,
   цвет-акцент) — из brand.json; «exactly ONE» там, где нужен один элемент.
4. В план: `youtube_metadata.cover_text`, `cover_prompt`, таблица рефов — в отчёт.

## Следующий шаг зрителя

- **Закреп лонга:** после ссылки воронки — ссылка на следующий ролик серии.
- **Конечная заставка** (выставляется в Studio, напомнить в листе публикации): одно видео
  «лучшее для зрителя» и одно из той же серии, элементы на все 20 секунд.
- **Плейлисты** по сериям/гостям держать актуальными — из плейлиста смотрят дольше.
- **Ссылка воронки — первой в ссылках профиля канала.**
- **Вторая строка описания** повторяет то, что зритель реально получит по ссылке:
  открыть воронку самому и сверить формулировку с первым экраном.

## Проверка воронки (если переходов аномально мало)

1. Техническая причина раньше всех остальных: включены ли в Studio расширенные функции
   (без них ссылки в описании не кликаются), открывается ли ссылка с телефона.
2. Разные ссылки для описания, закрепа и QR (свой редирект или UTM) — иначе не понять,
   какой вход работает.

## Обложки и заголовки — тест, а не вкус

В Studio включить «Тестирование и сравнение»: до трёх вариантов обложки (и заголовка),
победитель выбирается по времени просмотра. Поэтому `alternate_titles` и 2–3 варианта
`cover_text` — не формальность. CTR через API не отдаётся — раз в неделю выписывать из
Studio, иначе слабую обложку не отличить от слабого ролика. Текст на обложке и плашках
проверять в уменьшенном виде: часть аудитории смотрит с телевизора.

## Куда записать

`project.youtube_metadata`: `title`, `alternate_titles`, `description`, `tags`,
`hashtags`, `chapters`, `pinned_comment`, `cover_text`, `cover_prompt`.
Для шортса — `project.related_long`.

## Лист публикации

Когда упакована пачка: `python scripts/publish/publish_sheet.py <prefix> --start
YYYY-MM-DD [--shorts-time 12:00 --long-weekday 5 --long-time 18:00 --utc-offset 3]` →
`edit-plans/<prefix>_ПУБЛИКАЦИЯ.md` (для ручной загрузки) и `_ЗАГРУЗКА.json` (для
`scripts/publish/youtube_upload.py`, если пользователь настроил OAuth — docs/publish.md).
Слоты по умолчанию — `publish_slots` из `channel/settings.json`.
