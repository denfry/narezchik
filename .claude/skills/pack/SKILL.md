# /pack

1. Найти планы: `edit-plans/<аргумент>*.json` со `stage` `final` (или `rendered`, если
   пользователь просит упаковать без критики — предупредить).
2. Агент `packager` — все ролики одним запуском, в конце `publish_sheet.py`
   с датой старта (из аргумента или спросить).
3. Показать пользователю заголовки и путь к `edit-plans/<prefix>_ПУБЛИКАЦИЯ.md`.
4. Загрузка — **только по явной просьбе** пользователя и только после его подтверждения
   списка и расписания (это публикация, её не отменить незаметно):
   `python scripts/publish/youtube_upload.py --schedule edit-plans/<prefix>_ЗАГРУЗКА.json --dry-run`,
   показать, затем без `--dry-run`. Нет OAuth — инструкция `docs/publish.md`.
   Ролики грузятся приватными с отложенной публикацией.
