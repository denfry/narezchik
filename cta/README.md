# cta/ — материалы для врезок-призывов

Сюда кладутся ваши файлы для CTA: куда зритель пойдёт после ролика (курс, бот, канал,
продукт). В git не попадают (кроме этого README) — это ваши видео и картинки.

Агент-монтажёр (skill `cta-director`) выбирает, что и где ставить, по этому
инвентарю и разделу «Воронка» в `channel/profile.md`. Если папка пустая — ролики
собираются без врезок, это не ошибка.

## Что можно положить

| Файл | Формат | Для чего |
|---|---|---|
| `tail_vertical.png` | 1080×1920 (или 2160×3840) | финальная плашка Shorts, 2–3 с после панчлайна |
| `tail.png` | 1920×1080 (или 3840×2160) | финальная плашка лонга, середина пустая под элементы YouTube |
| `plate.png` | ~1536×352, с прозрачностью | маленькая плашка поверх говорящего |
| `invite.mp4` | любое | видео-зазывалка, где спикер сам приглашает (для лонгов, 8–15 с) |
| `promo_*.mp4` | любое | короткие видеокадры для врезки уголком |

Плашки без дизайнера: `python scripts/pipeline/make_cards.py tail cta/tail.png`,
`python scripts/pipeline/make_endplate.py cta/plate.png` — тексты и цвета из
`channel/brand.json`.

## Подводные камни

- Файлы с дронов и экшн-камер часто несут второй видеопоток — mjpeg-превью. Рендер берёт
  первый поток (`-map 0:v:0`), но если врезка в готовом ролике стоит стоп-кадром — дело в этом.
- Зазывалка часто записана тише подкаста на 8–12 LU: замерьте `python
  scripts/pipeline/probe_video.py cta/invite.mp4` и поставьте `gain_db` в сегменте.
