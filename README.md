# Нарезчик

**Команда ИИ-агентов на Claude Code, которая делает из длинных видео готовые Shorts и
лонги — под стиль вашего канала.**

Кладёте подкаст, интервью или стрим в `input/`, пишете `/shorts input/podcast.mp4` — и
редакция из девяти агентов находит сильные моменты, собирает речь с хуком, ставит кроп на
говорящего, наезды, карточки, субтитры, музыку, байты на ваш оффер и финальный CTA, рендерит в 4K, сама себя критикует и пишет
заголовки с описаниями. Вы подтверждаете выбор моментов и принимаете результат.

- **Подстраивается под канал.** `/setup-channel @ваш_канал` выгружает ваши ролики через
  YouTube API, смотрит, какие форматы, заголовки и обложки у вас заходят, и пишет профиль,
  по которому работают все агенты.
- **Рассчитан на Claude Pro ($20).** Рутину (нарезка по паузам, субтитры, кроп по лицу,
  рендер) делают скрипты, а не модель; техник работает на Haiku; режим экономии по умолчанию.
- **Качество рендера.** Один проход `filter_complex` вместо цепочки перекодов, 4K/1440p
  мастер (YouTube даёт VP9, а не мыльный AVC), ровные стыки без выпавших кадров и щелчков,
  −14 LUFS, собственные LUT без чужих лицензий.
- **Прозрачно и прерываемо.** Каждое решение записано в план `edit-plans/<id>.json`:
  можно поправить руками и перерендерить, можно закрыть всё посреди монтажа и продолжить.

## Быстрый старт

```bash
git clone <этот репозиторий> narezchik
cd narezchik
install.cmd            # Windows (двойной клик)
./install.sh           # macOS / Linux
```

Установщик проверит Python, ffmpeg, GPU и покажет меню: поставить всё рекомендуемое
автоматически, выбрать компоненты вручную или только проверить. Подробно — [docs/setup.md](docs/setup.md).

Затем:

```bash
claude                                   # открыть папку в Claude Code
/setup-channel @ваш_канал                # один раз: профиль стиля канала
/shorts input/podcast.mp4 5              # 5 готовых Shorts
/long input/podcast.mp4                  # или лонг 5–15 минут
/fix podcast_short02 начало затянуто     # правка словами
/pack podcast 2026-10-01                 # заголовки, описания, расписание
/comments                                # ответы на комментарии и модерация
```

## Команда

| Агент | Роль |
|---|---|
| `channel-analyst` | разбирает канал, пишет профиль стиля, бренд и контент-правила |
| `idea-scout` | ищет сильные моменты и темы, составляет контент-план |
| `scriptwriter` | собирает речь: хук, вырезка воды, порядок, удержание |
| `shorts-editor` | монтаж Shorts: кроп на говорящего, акценты, пословные субтитры, байт-мост в лонг |
| `long-editor` | монтаж лонгов: главы, карточки, врезки, байт в середине, музыка на швах |
| `render-engineer` | приём видео, транскрипция, рендер, техконтроль |
| `qc-critic` | независимая оценка ролика и адресные правки |
| `packager` | заголовки, описания, закрепы, обложки с референсами, расписание |
| `community-manager` | ответы на комментарии с прогревом и байтами, правила модерации |

Как они передают работу друг другу — [docs/agents.md](docs/agents.md).

## Что нужно

- Windows 10/11, macOS или Linux; Python 3.10–3.12; ffmpeg (ставится установщиком).
- [Claude Code](https://claude.com/claude-code) и подписка Claude Pro или выше.
- Для `/setup-channel` — бесплатный YouTube Data API ключ ([как получить](docs/setup-channel.md)).
- Желательно NVIDIA GPU (транскрипция в разы быстрее); без неё всё работает на CPU.
- Для 4K-лонгов — 8–16 ГБ RAM. Нет мощного ПК — можно рендерить на своём сервере ([docs/remote.md](docs/remote.md)).

```
.claude/agents/     роли агентов
.claude/skills/     команды (/shorts, /long…) и методички стадий
channel/            профиль вашего канала (создаётся /setup-channel)

scripts/publish/    лист публикации и загрузка

cta/                ваши материалы для врезок-призывов
input/ transcripts/ edit-plans/ ideas/ temp/ output/   рабочие папки
```

## Ответственность

Нарезчик режет чужую речь — права на исходники, музыку и врезки на вашей стороне.
Агенты по умолчанию не берут фрагменты из стоп-списка (`channel/content-rules.md`) и
спрашивают про спорное, но решение и ответственность за публикацию — ваши.
